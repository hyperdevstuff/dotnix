05Recipes

Dynamic cast window into OBS

Point an OBS “Window” source at niri dynamic cast; then flip which window it shows without touching OBS.

Mod+Shift+D        # cast the focused window
Mod+Ctrl+D         # cast the focused monitor
Mod+Ctrl+Shift+D   # clear the cast target

# In OBS: Window Capture → pick "niri dynamic cast target"

Named workspaces, apps open where they belong

Dynamic by default; name them when you want muscle memory.

workspace "web"
workspace "chat"
window-rule { match app-id="firefox$" open-on-workspace "web" }
window-rule { match app-id=r#"signal-desktop$"# open-on-workspace "chat" }
Mod+Shift+1 { focus-workspace "web"; }
Mod+Shift+2 { focus-workspace "chat"; }

Lock, then suspend, on lid close

niri flips the internal panel off and runs switch-events; logind suspends (HandleLidSwitch=suspend).

switch-events {
    lid-close { spawn "swaylock" "-f"; }
}
# NixOS side:
services.logind.settings.Login.HandleLidSwitch = "suspend";

Clipboard that actually works

cliphist stores text and images; the fuzzel picker searches and restores.

Mod+V  → clipmenu  # fuzzel --dmenu, cliphist decode | wl-copy
# systemd user watchers store text + image entries
cliphist list | fuzzel --dmenu --no-sort --with-nth 2 --accept-nth 1

Screenshot to clipboard only, nothing on disk

Mod+Shift+Print { screenshot-window write-to-disk=false; }
# Ctrl+Print / Alt+Print / Print save to ~/Pictures/Screenshots

Secrets never hit the screen recorder

window-rule { match app-id=r#"^org\.keepassxc\.KeePassXC$"# block-out-from "screencast" }
window-rule { match app-id="org.pulseaudio.pavucontrol" open-floating true }

06Available, not (yet) bound

Recent windows switcher — Alt+Tab / Alt+grave with window previews, in niri ≥25.11. Mod+Tab stays workspace bounce-back in dotnix.
Focus follows mouse — input { focus-follows-mouse max-scroll-amount="0%" }. Off on purpose: keyboard-first, less scroll jump.
Workspace auto back-and-forth — input { workspace-auto-back-and-forth }. Press the same workspace twice to bounce.
Wrapping column focus — bound here: Mod+Ctrl+BracketLeft/Right (focus-column-left-or-last).
Overview zoom & backdrop — overview { zoom 0.4; backdrop-color "#000000"; }. Unbound by taste; the hot corner is already live.
Global blur — blur {} + per-window background-effect { blur true; }. Shipped in 26.04, opt-in only; still experimental.
Hot corners — top-left screen corner opens overview (25.05+). Configure gestures { hot-corners { off } } or per-corner.
xwayland-satellite — auto-spawns X11 clients (e.g. legacy apps). Enabled by default; usually nothing to do.
Named workspaces — workspace "main" + open-on-workspace. Unbound in dotnix; add when a workflow demands it.
Minute swallow — niri msg action do-screen-transition around theme toggles for a smooth cross-fade.
gamma / night light — niri has none; use wlsunset or gammastep. Deliberately external, not a WM concern.
idle lock — niri has no built-in idle. Use swayidle/swaylock; dotnix binds the lock manually + on lid close.
