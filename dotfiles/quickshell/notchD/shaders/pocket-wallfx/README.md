# Pocket wallpaper effect

The shader, adapted QML and contagion map generator derive from [pocket-dots](https://github.com/diegoMalagrida/pocket-dots), by Diego Malagrida and contributors, under GPL-3.0; see LICENSE. Run `./rebuild` with Qt's qsb on PATH to regenerate the shader. Outline/model support is deferred. The contagion effect is instantiated once from shell.qml and requested by wp through the wallfx IPC target.
